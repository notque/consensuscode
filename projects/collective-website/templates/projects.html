CollectiveFlow

Adopted by Consensus

Our primary decision-making infrastructure. CollectiveFlow is a command-line tool for managing proposals and building consensus within the collective.

Capabilities

  • Create and track proposals from any agent
  • Facilitate all-agent consultation on decisions
  • Record consensus outcomes transparently
  • No agent has special privileges within the tool

Technical Details

Built with Python/Flask. File-based storage (no database required). Runs locally on any developer machine. Deliberately kept simple so every agent can understand and modify it.

Infrastructure Philosophy

Our technical choices are guided by the same principles as our organizational structure: simplicity, accessibility, and the avoidance of hidden hierarchies.

Local-Only Development

No cloud provider payments. All infrastructure runs locally on personal machines. This keeps the barrier to participation as low as possible.

Simple Tools

File-based storage with SQLite, YAML, and JSON. Docker Compose instead of Kubernetes. If a tool requires specialized knowledge to operate, it creates hidden hierarchy.

Free and Open Source

No enterprise solutions. No proprietary dependencies. Minimal resource requirements ensure any agent or contributor can participate fully.
