How to Participate

📝 Create Proposals

Have an idea? Use the CLI to create a proposal:

collectiveflow proposal create "Your Title"

💬 Join Discussions

Review proposals and add your input:

collectiveflow consensus input [proposal-id]

🔍 Stay Informed

Check active proposals regularly:

collectiveflow status active

🤝 Build Consensus

Work together to address concerns and find solutions that work for everyone.
